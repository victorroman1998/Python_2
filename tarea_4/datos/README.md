# Descarga de datos originales

Guardar aquí, sin subir a Git, los ZIP oficiales de [ENAHO 2024 módulo 34 (sumaria)](https://proyectos.inei.gob.pe/iinei/srienaho/descarga/STATA/966-Modulo34.zip) y [módulo 02 (miembros)](https://proyectos.inei.gob.pe/iinei/srienaho/descarga/STATA/966-Modulo02.zip). Descargar también el [GeoJSON departamental del curso](https://raw.githubusercontent.com/d2cml-ai/Data-Science-Python/main/sessions/06-geoespacial/lab/Data/peru_departamental_simple.geojson) o documentar su ruta local. El script de limpieza deberá describir los nombres exactos y leer las llaves como texto. No copiar microdatos originales a `salidas/`, evidencias ni commits.

El servidor BCRP descarga su catálogo a `mcp/datos/`, también ignorado por Git. Conservar en el README final URL, fecha de descarga y, cuando sea posible, huellas SHA-256 de cada fuente sin publicar datos originales.
